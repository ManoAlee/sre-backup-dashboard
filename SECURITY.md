# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is paramount in SRE infrastructure and disaster recovery platforms.

If you discover a security vulnerability or credential leak within this codebase:
1. **Do NOT open a public GitHub issue.**
2. Send an advisory report via private email to: `security@enterprise.local` or open a GitHub Private Vulnerability Advisory.
3. Include detailed steps to reproduce the issue, attack vectors, and potential impact.
4. We aim to acknowledge reports within 24 hours and issue a CVE/patch within 7 calendar days.

## Data Sanitization & White-Label Policy

This project strictly adheres to zero-PII and white-labeling standards. All internal IPs, domain names, corporate entities, and credentials in templates are sanitized with RFC-compliant examples.
